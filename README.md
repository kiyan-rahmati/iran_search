# ARYA — Iranian-inspired search start page

A lightweight, Persian RTL homepage concept with a Faravahar-inspired mark, time-aware greeting, dynamic scenic wallpapers, search engine selector and editable quick links.


## Run locally
Open `index.html` in any modern browser. No build tools or server are required.

## Structure
- `index.html` — page markup
- `assets/css/style.css` — UI styling, glassmorphism and responsive layout
- `assets/js/app.js` — clock, backgrounds, search engines, theme and shortcuts
- `assets/images/` — reserved for self-hosted wallpapers/icons
- `docs/` — product notes and roadmap


## Features
- Persian clock/date and time-based greeting
- Wallpaper carousel (remote image URLs; internet required)
- Search via Google, Bing, DuckDuckGo, or Brave
- Quick-link tiles and user-added links saved in localStorage
- Theme toggle
- Responsive layout

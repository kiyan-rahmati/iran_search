# IranSearch / ایران سرچ

Front-end project based on the supplied Figma direction. Open `index.html` directly or serve this folder with any static server.

## Included
- RTL responsive dashboard and search landing page
- Search tabs, results toggle, theme persistence, profile controls, live Persian clock/date
- Modular CSS and JavaScript files under `assets/`
- No build step or framework dependency required

# Product brief

**Working name:** ARYA / آریا  
**Positioning:** A clean, Persian-first browser start page inspired by Iranian landscape and visual heritage.


## Experience principles
- Fast and calm: search remains the central action.
- Persian-first: RTL, localized clock and date, culturally rooted visuals.
- User control: selectable engine, editable shortcuts, background and theme.
- Privacy: settings stay in localStorage in this prototype; no analytics or accounts.
- Honest scope: this is a start page, not yet a browser or an independent search index.


## Initial audience
Persian-speaking users who want a personalized, attractive browser home page and quick access to search and favorite sites.
